# 智仓成果弹窗 Markdown 预览功能设计

## 1. 目标与背景

在 Silo 智仓的博主空间「版本与成果」页面中，用户点击「查看报告」和「查看 Skill」时，当前仅展示原始 `<pre>` 纯文本，缺少富文本 Markdown 预览效果。
同时，用户通过 Tailscale 外网或局域网访问边缘服务器上的服务，要求所有资源完全自包含（无外部 CDN 依赖），保证在任意网络环境下稳定运行。

## 2. 功能设计

### 2.1 弹窗交互增强（`artifact-dialog`）
- **默认模式**：打开「查看报告」或「查看 Skill」时，默认展示排版美化后的 Markdown 预览视图。
- **视图切换**：工具栏增加「预览」与「源码」两个状态切换按钮，点击可在渲染后的 HTML 与原始 Markdown 文本间随时切换。
- **快捷复制**：新增「一键复制」按钮，点击将原始 Markdown 写入剪贴板，并提供「已复制」的临时反馈提示。
- **快捷下载**：保留原有「下载 Markdown」按钮。

### 2.2 Markdown 解析与渲染策略
- **自包含解析器**：在前端内置轻量、标准、可靠的 Markdown 解析器（支持 GFM 语法：标题、列表、引用块、代码块、行内代码、粗体/斜体、表格、水平分割线、YAML Frontmatter）。
- **零外部请求**：无需加载任何 CDN 或第三方脚本，完全内嵌于页面或本地静态资源中。

### 2.3 智仓主题排版规范
- **标题**：
  - H1：主色调深蓝（`#173f76`），带底部轻微分割线。
  - H2：典雅宋体加粗，左侧带智仓专属金色标记条（`#e8a13a`），增加视觉层级。
  - H3/H4：清晰黑体加粗。
- **代码块与 YAML**：
  - 针对 `SKILL.md` 顶部的元数据和代码段，采用浅蓝灰底色（`#edf3f8`）、细边框、圆角与等宽字体。
- **表格**：
  - 自动居中、自适应宽度、边框完整、表头背景微深、隔行斑马纹。
- **引用块**：
  - 浅底色配合左侧金色实线边框。

## 3. 测试与验证
1. 打开历史版本的「查看报告」，验证 H1~H4、列表、表格、加粗、引用块的渲染效果。
2. 打开历史版本的「查看 Skill」，验证 YAML Frontmatter、多行代码块、任务列表的渲染效果。
3. 切换「预览」与「源码」模式，验证内容与排版正确无误。
4. 测试「复制全文」功能，确认剪贴板内容与反馈提示正常。
5. 运行已有的自动化测试套件确保无破坏性变更。
